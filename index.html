Digital Stopwatch using
Synchronous Sequential Circuits

A digital stopwatch measures elapsed time using clock pulses, sequential states, counters and display logic. Every count in this project happens on a clock edge — never on a raw timer.

◷

Clock

Generates the periodic rising edges that drive every state and counter change.

▦

State Register

Holds the current FSM state (IDLE, RUNNING, STOPPED) between clock edges.

#

Counter

MOD-60 seconds and minutes counters that increment only on an enabled clock edge.

Problem & Objective

Problem

Manual timing is not accurate for many applications. A digital stopwatch provides accurate elapsed-time measurement using digital circuits rather than human reaction time.

Objective

Design and simulate a stopwatch using synchronous sequential logic, where all state and counter changes are synchronized to a common clock signal.

Key Requirements

  • Generate clock pulses
  • Define timing states
  • Implement counters
  • Implement START
  • Implement STOP
  • Implement RESET
  • Display elapsed time
  • Test timing transitions

About This Project

Assumptions

  1. The simulation uses a software-generated clock.
  2. Default clock frequency is 1 Hz.
  3. The stopwatch uses MM:SS display.
  4. Seconds counter is MOD-60.
  5. Minutes counter is MOD-60.
  6. Counter changes only on the rising edge of the clock.
  7. START enables counting.
  8. STOP holds the current count.
  9. RESET clears the counters and returns the system to IDLE.

Project Info
